A

Everywhere

Every word in the game is Silkscreen: menus, the Lab, HUD, kill feed, name tags, damage numbers.

  • Strongest retro look, one style everywhere.
  • Long descriptions (Lab step texts, the "what it does" line) get harder to read on a phone.
B · RECOMMENDED

Titles, buttons, numbers

Silkscreen for anything short and loud: titles, buttons, tabs, chips, score, ability names, kill feed, damage numbers and name tags. Sentences stay in the clean font.

  • Keeps the arcade look where you see it most.
  • Descriptions stay easy to read on small screens.
C

Menus only

Main menu, Lab and species picker in Silkscreen; the match HUD and in-world text stay as they are now.

  • Smallest change.
  • The game looks like two styles mixed.
SIZE

Shrink to fit

Silkscreen Bold is about 13% wider than our current fonts. "Shrink to fit" scales each text down just enough to keep it in the same space, so nothing gets cut off or pushes buttons around. "Same size" keeps the size but long labels can cut off.
