ICON (512 × 512)

The icon is the square tile in the Roblox app. It is also shown as small as 150 × 150, so the small preview is the one to judge. Each direction comes without text (1) and with the name (2).

ARaptor up close, T-Rex behind

THUMBNAILS (1920 × 1080)

These sit next to the trailer on the game page. Roblox can rotate 2 to 5 active thumbnails per player and track which one gets more plays. Text stays at the top, because the bottom edge gets covered by the player count.
