Left: name tag and pre-game lineup over the sky. Right: kill feed and leaderboard rows. Rows top to bottom: NOW (Silkscreen), 1 Gotham Black, 2 Builder Sans, 3 Fredoka One, 4 Roboto Mono.

Zoomed 2x

The options

  1. Gotham Black: the heaviest and boldest. Reads clearest at the smallest kill feed size.
  2. Builder Sans: Roblox's own font. Clean and a bit narrower, so #100 takes less room.
  3. Fredoka One: rounded and chunky, the game's old font. Friendly but softer at 10.
  4. Roboto Mono: every digit the same width, so badges line up neatly on the board. Thinnest of the four.
