The mini dinos (bug, not a choice)

Every player dino is scaled up by RaptorScale (Raptor, Pachy, Herrera, Teno, Therizino, Dilo, Troodon x2, T-Rex x1.63), but for bots it only has Raptor, Pachy and T-Rex. So practice Herrera, Teno, Therizino, Dilo and Troodon bots spawn at half a player's size. Fix: RaptorScale 1.9 scales those five bot species the same way as the player ones (same distance keys and ground lift), behind a switch. It goes in with whichever spawn and marker picks you make.

CoD spawns

Infinity Ward: each spawn is scored on "enemy locations, friendly locations and visibility" and the best one wins (MP1st). In Hardpoint, which side you spawn on depends on who holds the useful side of the current or next point; a team that anchors a side keeps its spawns there until it is pushed (spawn flips) (Mitch Cactus).

CoD next point

"10 seconds before the next Hardpoint activates, the next hardpoint will appear, however it will be locked" (Call of Duty BO6 guide). Our HUD only writes the next name in text; there is no marker on it.

Edge markers

The usual method: take the direction from the screen centre to the target and push the marker along that line to the screen edge, with an arrow turned the same way (Envato Tuts+). Behind the camera, flip the direction so it never jumps to the wrong side.
