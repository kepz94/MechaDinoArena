    Check this first: you said the Herrera "deals extra damage attacking from trees". In the code (SlashServer 1.8) a drop attack from a tree does normal slash damage. The +30% is only on a drop from a glide (Glider Wings step 3, GliderDropMul 1.3). From a tree, Tree Stalker gives reach 40 → 55, a charge back, hiding on tree tops and a 0.5 s stun. So the copy here says what the game does today. If you want a real tree-drop damage bonus, that is a separate change.
