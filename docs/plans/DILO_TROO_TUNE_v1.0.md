## Rules
**Dilo spit**
- Flight speed: DiloModelData 1.14 DiloDartSpeed 40 (Long Spit still multiplies it). The spit rate stays DiloSpitGap 0.35.
- Ammo (server-owned, per character; spit-only dilos): DiloSpitMag 5, DiloSpitReload 3 s (DiloModelData 1.14). Published on the
  character: DiloSpitLeft (0..5), DiloSpitReloadAt (server time the reload ends; 0 when not reloading).
  - New character: 5.
  - Accepted spit: −1. Reaching 0: DiloSpitReloadAt = now + 3. At DiloSpitReloadAt: 5, DiloSpitReloadAt = 0.
  - Spit with 0 left (reloading): refused "reloading".
  - Reload starts only at 0 (no partial reload).
  - Venom Overdrive: when DiloOverdriveUntil moves into the future, ammo refills to 5 (reload cancelled); spits while it runs
    don't use ammo.
  - Cold Blood star: when the server stamps DiloDartResetAt, ammo refills to 5 (reload cancelled).
- Switch: DiloAttackServer script attribute DiloSpitAmmoEnabled (default true, read per request; false = 1.9, no ammo).

**Dilo ammo on screen (PC + phone)** — the mockup's look
- The ATTACK pip row shows 5 pips (the Troodon / Herrera pip row): full up to the shots left; while reloading all 5 fill together
  from the bottom over the reload, and the ATTACK button / tile dims (0.5); a tap does nothing until it's full.
- Client mirror: DiloAttackTest keeps DiloLocalSpitLeft (drains on the tap, follows the server's DiloSpitLeft / ReloadAt), so the
  pips move at once and a tap at 0 is refused locally.

**Sonic Hiss (B)**
- Range x DiloPartHissRangeMul 2 (20 / 25 / 30 -> 40 / 50 / 60) and the half angle x DiloPartHissAngleMul 2 (35 -> 70, a 140° cone),
  kept at most 90 (half angle). The stamps carry the new numbers, so the FX follow. Knock and silence unchanged.
- Switch: DiloMovesServer script attribute DiloHissBigEnabled (default true, read per press; false = as now).

**Troodon double tap**
- Single tap: as now (throw; at release the closest enemy in front).
- Double tap: a second tap within TrooDoubleTap 0.3 s of the last accepted local throw, while that pod is still in the hands
  (before its 0.34 s release), sends DinoTrooAttack:FireServer("ally", stamp) instead of a new throw (no charge used). The server
  marks that pending throw ally; at release it picks the closest living teammate (SquadRules: Hardpoint team / squad, not
  yourself) within TrooAllyAngle 45° and the pod's range; none -> the normal enemy pick.
- The aim ring (TrooFX) turns green (7BE37B) on the teammate pick.
- Switch: TrooAttackServer TrooDoubleTapEnabled and TrooAttackTest TrooDoubleTapEnabled (default true; false = as now).
