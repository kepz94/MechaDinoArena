## Fix 1 — Herrera run cadence (Wired) — MDA-323
**Grounding:** the Herrera runs ScurryPose at every moving speed (HerreraModelData `GaitScurry = true` :274,
`GaitAlwaysRun = true` :273; IdleAnimation init :759-769, :865). Cycle rate = min(dist / (ScurryStride × scale) / dt,
ScurryMaxHz) (init :768); defaults ScurryStride 3.2, ScurryMaxHz 5 (ScurryPose.luau:36); scale 2, walk 48 / run 90
(HerreraModelData :310 / :309) → 7.5 / 14 Hz wanted, both capped at 5 Hz (10 footfalls / s).
**Change:** herrera_generator next version writes model attributes `ScurryStride = 6`, `ScurryMaxHz = 3.5` (HerreraModelData
next version, body unchanged): 12 studs per cycle at scale 2 → walk 4 Hz → capped 3.5, run 3.5 Hz. No code change; the
attributes are the switch (remove them = today's look). Bots built from the same data follow.
**Acceptance:** walk and run read ~3.5 cycles/s in Play (diagnostic ScurryHz); feet don't skate visibly at walk; other
species unchanged.
